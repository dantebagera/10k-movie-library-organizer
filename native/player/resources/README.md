# Cinema Paradiso player icon

`cp-player.ico` is the Windows-native derivative of
`static/cinema-paradiso-icon-preview.png`, the existing Cinema Paradiso
application icon. It contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel
variants so Windows can use the same branded asset in the title bar, taskbar,
Alt+Tab view, and executable presentation without scaling one small bitmap.

When the authoritative application icon changes, regenerate this derivative
from that source rather than editing the native-player icon independently.
